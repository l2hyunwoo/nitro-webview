# Migration

The [official migration guide](https://l2hyunwoo.github.io/nitro-webview/guides/migration.html) covers switching from `react-native-webview` and upgrading from 0.1 to the 0.2 candidate.
[한국어 마이그레이션 가이드](https://l2hyunwoo.github.io/nitro-webview/ko/guides/migration.html)

The 0.2 candidate is unreleased; the package version remains `0.1.0` until release checks pass.
Match the guide to your installed version. For published behavior, use the README included in that package version.
