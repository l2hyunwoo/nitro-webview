# Migration

The [official migration guide](https://l2hyunwoo.github.io/nitro-webview/guides/migration.html) covers switching from `react-native-webview` and upgrading from 0.1.0 to 0.2.0.
[한국어 마이그레이션 가이드](https://l2hyunwoo.github.io/nitro-webview/ko/guides/migration.html)

This guide describes `0.2.0`. Match it to your installed version and rebuild the native app when upgrading.
For older behavior, use the README included in that package version.
